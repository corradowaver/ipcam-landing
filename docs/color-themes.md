# Цветовые темы макета «Вместе»

Согласовано 16 сентября 2026 года: сохраняем исходные пастельные акценты,
уточняем нейтральные поверхности и добавляем тёмную тему. Сине-зелёная
альтернатива из обсуждения не используется. Обе темы перенесены в React.

## Сохранённые варианты

- [Светлый макет](../mockup-cozy/index.html).
- [Тёмный макет](../mockup-cozy/index-dark.html).
- [Светлый HTML-фрагмент](../mockup-cozy/vmeste-prototype.fragment.html).
- [Тёмный HTML-фрагмент](../mockup-cozy/vmeste-prototype-dark.fragment.html).

Каждый HTML-файл содержит все пять страниц, фотографии, шрифты, настройки
анимации и локальную демонстрационную форму. Внешние ресурсы не требуются.
Тема зафиксирована в файле и не зависит от темы операционной системы.
Переходы между страницами сохраняют её. Это два варианта для передачи в разработку;
В React реализованы системный выбор темы, переключатель солнце/луна в шапке
и сохранение ручного предпочтения. Подробнее: [реализация](react-redesign.md).

## Правила переноса

- В React использовать те же смысловые роли; не делать инверсию цветов страницы.
- Основные кнопки и подписи рамок имеют тёмный текст на пастельной заливке.
  Контраст тёмного текста на розовой кнопке — около 5,64:1.
- В тёмной теме поверхности светлее общего фона. Большие лавандовые заливки
  заменены тёмной фиолетовой подложкой, яркий акцент остаётся небольшим.
- Жёлтый маркер сохраняет положение под нижней половиной слова. В тёмной теме
  слово жёлтое, подложка приглушённая; белый текст на ярком жёлтом не используется.
- Фотографии одинаковые в обеих темах: без инверсии, фильтров или затемнения.
  Координаты и цвета рамок также одинаковы. Каска обозначается сплошной мятной
  рамкой, отсутствие каски — розовым пунктиром и подписью.
- Hover, фокус, поля, сообщения ошибок, раскрытые детали, мобильное меню и
  настройки используют соответствующие теме роли. Контур фокуса — основной цвет
  текста; у primary hover розовый смешивается с постоянным тёмным цветом.
- Контраст отдельных пар не заменяет полный аудит доступности готового сайта.

## Сборка и проверка

```sh
node scripts/build-mockup.js
node scripts/build-mockup.js --check
npx playwright test --config tests/mockup/playwright.config.js
npm run check
```

На Windows предварительно выполнить `. ./scripts/setup-node.ps1`.
Редактировать общие файлы в `home/`, `subpages/`, `shared/` и базовую оболочку
светлого фрагмента. Тёмные файлы генерируются из светлых и не редактируются отдельно.
Сборка синхронизирует оба самостоятельных HTML и оба фрагмента; `--check`
проверяет все четыре результата.

Локальный просмотр: `node scripts/serve-mockup.js`, затем
`http://127.0.0.1:4174/index.html` или `http://127.0.0.1:4174/index-dark.html`.

Одна браузерная матрица запускается для двух тем: 360, 768, 1024 и 1440 px,
навигация, фото, рамки, раскрытие деталей, форма, клавиатура и анимации.
Снимки пяти страниц при 360/1440 px находятся в `mockup-cozy/previews/`:
светлые — `{page}-{width}.png`, тёмные — `{page}-{width}-dark.png`.
Это проверка Chromium с эмуляцией размеров; реальное мобильное устройство
и остальные браузеры требуют проверки при переносе и перед публикацией.
