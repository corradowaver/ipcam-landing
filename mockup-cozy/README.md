# Макет «Вместе» — cozy

Самостоятельный интерактивный макет с пятью страницами. На 16 сентября 2026 года
все страницы обновлены: это **предложение дизайна** с промышленными кадрами с
ракурса камеры видеонаблюдения, редакционной композицией и плавными анимациями.
React-приложение сохраняет предыдущую версию до отдельного переноса.

## Просмотр

Откройте `index.html` в браузере. Макет содержит навигацию между страницами,
мобильное меню, раскрываемые кейсы, настройку скругления и отключение анимаций.

Для просмотра через локальный сервер выполните из корня репозитория:

```sh
node scripts/serve-mockup.js
```

Адрес: [http://127.0.0.1:4174](http://127.0.0.1:4174). Сервер слушает только
локальный интерфейс и отдаёт один HTML-файл.

На главной и странице услуг «Показать анализ» управляет рамками обнаружения. Сценарии
раскрывают прежние описания задач. Все новые фотографии созданы ИИ и подписаны
как демонстрационные изображения; они не обозначают реальные внедрения.

Демонстрационная форма раскрывается в потоке страницы сразу под шапкой. Она
проверяет рабочую почту локально, не отправляет и не сохраняет данные. Кнопка
«Закрыть» и клавиша Escape очищают форму и возвращают фокус на вызвавшую кнопку.

## Содержимое

- `index.html` — самодостаточная версия для просмотра;
- `vmeste-prototype.fragment.html` — HTML-фрагмент; здесь редактируются общая
  оболочка, форма, навигация и исходные данные предложений и сценариев;
- `home/` — исходники новой главной: разметка, стили композиции, фотографий, схемы,
  адаптивности и движения, небольшой JS-контроллер;
- `subpages/` — разметка, стили и представление услуг, кейсов, цен и компании;
- `shared/` — общий жизненный цикл анимаций, фотографии и слой обнаружения;
- `assets/` — выбранные иллюстрации, фотографии WebP, исходные PNG и промпты;
- `previews/` — снимки desktop/mobile из браузерной проверки.

Изображения встроены в HTML, поэтому папка `assets` для просмотра `index.html`
не требуется. Шрифт Onest также встроен, поэтому макет не загружает внешние
ресурсы. Папка `assets` сохранена для дальнейшего редактирования.

## Редактирование и проверки

После изменений в `home/`, `subpages/`, `shared/` или ассетах запустите из корня:

```sh
node scripts/build-mockup.js
```

Скрипт обновляет размеченные области фрагмента и синхронизирует его с телом
`index.html`, сохраняя автономную оболочку. Сгенерированные области
`home:styles` / `home:script` содержат собранные стили и JS всех страниц.
Их и пять шаблонов редактируйте через исходники в `home/`, `subpages/`, `shared/`.
Зависимости для анимаций не добавлены. Проверка синхронизации:

```sh
node scripts/build-mockup.js --check
npx playwright test --config tests/mockup/playwright.config.js
```

Если локальный сервер уже запущен, перед тестом задайте
`PLAYWRIGHT_REUSE_SERVER=1`. Отдельно выполните `npm run check` для проекта.
